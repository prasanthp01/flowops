01 / THE PROBLEM

One escalation.
Several systems.

An incorrect shipment and a refund request can send an operations team between customer records, order history, stock levels and policy documents.

FlowOps brings those facts into a single auditable workflow. A research specialist collects evidence, a policy specialist checks the rules, operations prepares the next step, and a verifier checks it before the policy engine decides.

EXAMPLE JOURNEY

“This order arrived incorrectly. Can you resolve it?”

Investigate → prepare a proposal → enforce policy → record the outcome.

02 / THE ARCHITECTURE

State survives. Authority stays explicit.

A

Durable orchestration

PostgreSQL checkpoints, leased workers and fenced writes keep the workflow recoverable across restarts.

B

Scoped handoffs

Each specialist receives typed inputs, evidence references, a deadline and only its delegated tool permissions.

C

Policy before action

Amounts, identity checks and approval bindings are enforced in code. The fake gateway records one receipt per logical action.

04 / EVIDENCE & LIMITS
Claims with
clear boundaries.
What runs here
Real state-machine code, deterministic specialist adapters, mock HTTP connector requests and PostgreSQL audit records.
What the cost means
External LLM spend is zero because no model is called. Hosting and development costs are separate and are not measured in the simulator.
Performance
Each run displays measured end-to-end time, including queueing and approval waits. Release benchmark methodology and results are in the local repository handoff; these are not production capacity claims.
Security & recovery
Signed sandbox sessions, scoped run access, exact approval bindings, fenced workers and bounded retries. See the test report for verified cases and remaining limits.
Current limits
Synthetic data only. No live provider, enterprise connector or multi-tenant security claim. Public sessions are temporary and rate limited.
Interactive demonstration
Run one of five editable scenarios and inspect persisted events, approval decisions and the simulated action receipt.
