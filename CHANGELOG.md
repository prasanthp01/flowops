# Changelog

## 0.1.0 — 2026-10-13

Initial local synthetic MVP: durable supervisor plus four typed specialists, versioned refund policies, server-owned approval requests and authenticated decisions, mock HTTP ERP/CRM/inventory adapters, idempotent fake action receipts, failure/recovery handling, signed scoped sessions, SSE/polling and the same-page editable case study.

Includes regression/evaluation tests, Docker setup, bounded local benchmark, backup/restore and restart drills, security/operations documentation and a portfolio integration contract. Public deployment, live AgentOps/enterprise connectors, external webhooks and a recorded video are not included.
